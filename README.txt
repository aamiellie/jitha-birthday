JITHA'S BIRTHDAY WEBSITE 💗

QUICK FREE PUBLISHING WITH GITHUB PAGES
1. Unzip jitha-birthday-website.zip on your phone/computer.
2. Go to https://github.com and sign in.
3. Tap + (top-right) -> New repository.
4. Name it: jitha-birthday
5. Choose Public, then Create repository.
6. In the repository choose Add file -> Upload files.
7. Upload index.html (and any photo files you add) from this folder, then Commit changes.
8. Open Settings -> Pages.
9. Under Build and deployment, choose Deploy from a branch.
10. Select branch main and folder /(root), then Save.
11. Wait a few minutes. GitHub will show the published link in Settings -> Pages, usually:
    https://YOUR-USERNAME.github.io/jitha-birthday/

BEFORE YOU PUBLISH
- Open index.html in a text editor to personalize the letter and captions.
- To add photos, place the image files beside index.html. In each scrapbook card, replace:
  <div class="photo-placeholder">♡</div>
  with:
  <img src="your-photo.jpg" alt="Our memory" style="width:100%;aspect-ratio:4/4.5;object-fit:cover">
  Make sure the filename matches exactly.
- This starter includes no copyrighted music file. If you want music, use a song/audio file you have permission to share; add it to the folder and I can help add a play button.
- Test the published link on your phone before sending it.
